# Mapa de Puertos y Adaptadores

## Backend
- Puertos de entrada: auth, users, reports, alerts, activities, dashboard, audit.
- Puertos de salida: repositorios, cifrado, tokens, sesiones, auditoria, reloj, ids, IA, transacciones.
- Adaptadores de entrada: controladores Nest, jobs, guards.
- Adaptadores de salida: TypeORM, cliente IA, JWT, bcrypt, session store.

## Frontend
- Puertos de entrada: login, logout, reporte, dashboard, usuarios.
- Puertos de salida: API HTTP, storage, navegación, notificaciones.

## AI Service
- Puertos de entrada: analyze report.
- Puertos de salida: classifier rules, future ML model, logger.
